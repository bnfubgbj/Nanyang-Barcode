# NanyangBarcode 🏭

ระบบสร้างรายการสินค้าติดบาร์โค้ด — บริษัท นันยางมาร์เก็ตติ้ง จำกัด

## วิธีโหลด .exe

1. คลิก **Actions** (แถบด้านบน)
2. คลิก workflow ล่าสุด
3. เลื่อนลงมาที่ **Artifacts** → คลิก **NanyangBarcode** → โหลดได้เลย

## วิธีใช้งาน

1. ดับเบิลคลิก `NanyangBarcode.exe`
2. เลือกไฟล์ SO PDF
3. เลือกไฟล์ Stock โรงงาน
4. เลือกไฟล์ Stock 02
5. กด ▶ สร้าง Excel
6. ได้ไฟล์ `barcode_factory_*.xlsx` และ `barcode_bangwa_*.xlsx`
